# GastroAtlas 360

Jahon mamlakatlari gastronomiyasi va turizmi bo‘yicha ilmiy-statistik interaktiv sayt-prototip.

## Ishga tushirish

```bash
npm install
npm run dev
```

## Asosiy modullar

- 27 mamlakatning chuqurlashtirilgan gastronomik pasporti va qidiruv/saralash;
- 2019–2025 global turizm statistikasi;
- gastronomik turizm nazariyasi va tadqiqot metodlari;
- original GASTRONEXUS-7™ kompozit indeksi;
- uch mamlakatni real vaqtda solishtirish;
- motivatsiya, mintaqa va budjet asosidagi marshrut generatori;
- rasmiy hamda ilmiy manbalar registri.

> Eslatma: GASTRONEXUS-7™ baholari metodni namoyish qiluvchi ekspert-normalizatsion prototip. Patentga layoqatlilik alohida yangilik qidiruvi va ekspertizani talab qiladi.
